En base a las cartacteristicas identificadas en cada uno de los macros y
los estilos para este proyecto se decanta por lo que son los
microservicios y un estilo de capas para el desarrollo de software Se
eligio el estilo de capaz ya que utiliza una unica base de datos, ya que
al manejar una cantidad considerable de datos es mejor que todo se
maneje en un mismo sistema de BD, ademas de utilizar lo que es el macro
de microservicios ya que de esta manera podemos enfocarnos en lo que es
el desarrollo de cada una de las funciones de manera individual logrando
asi que en cuyo caso que algo no funcione no afecte a la estructura del
sistema mas alla de la funcion.
